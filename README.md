# AI Foundation — NumPy & Pandas

Google Colab notebooks from the data foundations part of my AI engineering studies: array computing with NumPy, data cleaning and analysis with Pandas, and an exploratory analysis of a real dataset.

## Notebooks
| Notebook | What it covers |
|---|---|
| [`AI_Section16_258_numpy.ipynb`](AI_Section16_258_numpy.ipynb) | **NumPy:** 1-D and 2-D arrays, `shape` / `ndim` / `dtype`, `reshape`, `astype`, `zeros` / `ones` / `arange`, aggregates (`sum`, `mean`, `max`, `min`), `flatten`, transpose, matrix multiplication with `dot`, random arrays |
| [`AI_Section16_259_pandas.ipynb`](AI_Section16_259_pandas.ipynb) | **Pandas:** Series and DataFrames, `head` / `tail` / `describe`, `iloc` / `loc`, filtering, statistics (mean, median, std), missing values (`isnull`, `dropna`, `fillna`), reading the Titanic CSV and exporting to Excel |
| [`AI_Section16_260_students_performance.ipynb`](AI_Section16_260_students_performance.ipynb) | **Students Performance analysis:** summary statistics of math, reading and writing scores, correlation between subjects, total and average score columns, averages by test-preparation course and by gender, pass rate and top scorers |

## Tech
Python · NumPy · Pandas · Google Colab

## Run
Open a notebook in Google Colab (File → Open notebook → GitHub → `mirzayv/ai_foundation`) and run the cells top to bottom. The Pandas and Students Performance notebooks ask you to upload the CSV file (Titanic / StudentsPerformance from Kaggle).
